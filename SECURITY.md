# Security policy

Please report vulnerabilities privately through GitHub: **Security > Report a vulnerability** on this repository. Do not open a public issue.

Include what you found, how to reproduce it, and what an attacker could do. You will get a reply within a week, and a fix or a plan soon after. Reporters are credited in the release notes unless they prefer not to be.

Only the latest release receives security fixes while onstreak is below 1.0.
